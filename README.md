# Redneck Farm

Redneck Farm is a lightweight multiplayer farming game prototype with a down-home holler vibe.

## Run it

```bash
python app.py
```

Then open `http://127.0.0.1:8000` in two browser tabs and play together on the same shared farm.

## What you can do

- Join the co-op with a farmhand name
- Plant corn, taters, okra, or pumpkin
- Water crops until they're ready
- Harvest shared plots and climb the leaderboard
- Watch the shared activity log update for everyone

## Run tests

```bash
python -m unittest discover -s tests -v
```
